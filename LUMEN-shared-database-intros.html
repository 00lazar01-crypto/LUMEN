Video sources

Enter an HTTPS embed URL or paste iframe embed HTML. Use {tmdbId} or {imdbId} for the title ID; show templates also need {season} and {episode}. {id} means TMDB ID when available, otherwise IMDb ID. Leave a backup blank to disable it. Templates apply to identified embed titles, not local files, direct videos or trailers.

Lumen Player

Configure detected sources, test playback, and choose or clear the preferred source. With no default selected, Lumen keeps the embedded website. A selected default is used only when that exact host is detected.

Library metadata

Refresh titles against TMDB and its linked IMDb IDs. This updates available ratings, artwork, title logos, descriptions, and episode details, and checks shows for newly listed episodes.

Accent color

Changes only the LUMEN logo, row headings and selected-title underline/highlight. All other text keeps its original colors.
